## Task 3 — 严格 M0–M1 输运对比

在共同有效的物理时间窗口，计算三个观测深度：

z/H=0.9、0.75、0.5。

保留实际 BOX 控制面位置。

对每个深度计算：

1. M0 和 M1 的累计总盐通量；
2. 额外累计盐通量 ΔC=C_M1−C_M0；
3. 初始库存修正后的上部盐库存差；
4. 对流与扩散通量的分别贡献；
5. 归一化额外输运 ΔC/I_ref；
6. 表层平均盐浓度、局部最大浓度及其差异；
7. 扰动标准差、模态投影与时空浓度结构。

使用模型真实守恒量 phi*Sw*x，明确其单位及物理解释，不将其直接称为真实 kg 或 mol 盐质量。

必须区别：

- 额外向下输运增强；
- 原有净向上盐供应减少；
- 总盐输运变化；
- 扰动相关对流通量。

这几个概念不可混同。

同时验证：

D_I + ΔC = R_M1 − R_M0

其中 D_I 已经扣除了初始库存差。

若 M0/M1 的接受时间步不一致，优先采用共同物理时刻。必要时开发经过测试、守恒一致的累计通量时间对齐方法，显式报告时间对齐误差，不得直接按行或时间步编号比较。
