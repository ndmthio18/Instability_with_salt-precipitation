## Task 1 — Prepare the staged background validation

- One horizontal cell, 200 vertical cells;
- Original vertical grid and constitutive laws;
- Original evaporation and bottom boundary conditions;

## Task 2 — First execute the T validation

Run a new bounded simulation from t=0 to T.

Verify:

1. Exact horizontal equality of pressure and concentration;
2. Agreement with the previous one-cell background during common accepted times;
3. Water and salt conservation;
4. Regional inventories and seven-plane fluxes;
5. No failed Newton iterations hidden by timestep acceptance;
6. Correct solubility stopping and event records.

Use the registered tolerances, including the 1e-14 horizontal-uniformity criterion and the existing physical bridge criteria.

If the T validation fails, stop and diagnose. Do not automatically extend.

## Task 3 — Conditional 4T validation

Only after the T results pass, prepare a separate continuous run from the same initial state to 4T.

Do not claim an unverified restart from T.

Compare the new run's first T window with the accepted T validation, checking fields, budgets and numerical trajectories.

Monitor convergence, residuals, actual accepted timesteps and horizontal uniformity throughout the full interval.

Stop at the first local solubility threshold crossing.

If the background reaches 0.1 before 4T, preserve the event interval and do not extrapolate beyond the stopping point.

Apply the revised approved time and storage budgets; report actual costs and any deviations.

## Task 4 — Recompute zero-mode and conservative responses

For R24 and R48, compare the existing M0/M1 trajectories against the validated background over their common physically admissible time window.

Compute:

- Seeded 2D minus strict background;
- Unseeded 2D minus strict background;

- Relative effects against contemporaneous background inventory;

Use actual accepted times. Do not interpolate conservative cumulative fluxes without a validated procedure.

Keep the distinction between zero-mode concentration response and true conservative salt redistribution.
