# Task 2 — Quantify post-onset perturbation amplification

这是本轮最重要的任务。

利用已有每步 `sigmatop` 数据，分析 onset 之后扰动如何变化。

对于满足 Paper 1 resolved-onset 检测条件的运行，首先计算：

### 2.1 Amplification factor

\[
G_{\mathrm{end}}=
\frac{\sigma_{\mathrm{end}}}{\sigma_{\min}}
\]

同时计算：

\[
G_{\mathrm{max}}=
\frac{\max_{t\geq t_{\mathrm{detect}}}\sigma(t)}
{\sigma_{\min}}
\]

分别表示：

- 模拟终点相对最小值的放大倍数；
- onset 后曾达到的最大放大倍数。

此外记录初始标准差、最小标准差、最终标准差、最大标准差以及相应时间。

不能仅根据放大倍数判断扰动显著性。

### 2.2 Relative perturbation magnitude

计算：

\[
A_{\mathrm{rel}}(t)
=
\frac{\sigma_{\mathrm{top}}(t)}
{\overline{x}_{\mathrm{top}}(t)}
\]

重点记录终点值与可观测的最大值。

这有助于区分：

- 从极小值增长很多倍，但绝对扰动仍非常小；
- 扰动不仅增长，而且已经相对于背景盐浓度达到较大幅度。

不要将任何未经验证的相对幅值阈值直接称为 nonlinear onset。

### 2.3 Post-onset observation window

计算：

\[
\Delta t_{\mathrm{post}}
=
t_{\mathrm{end}}-t_{\mathrm{detect}}
\]

以及：

\[
R_t=\frac{t_{\mathrm{end}}}{t_{\mathrm{detect}}}
\]

但必须明确，这两个量衡量的是时间覆盖，并不直接衡量增长强度。

还需要记录：

- onset 后有效采样点数量；
- onset 后是否接近溶解度阈值；
- 运行是否因为请求终点结束；
- 是否因数值故障、人工中断或其他原因停止。

对于 weak-interval、immediate-growth、right-censored 等运行，不允许将候选最小值自动当作 resolved \(t_{\mathrm{detect}}\)。

可以另外使用明确标记的候选转折时间进行探索性分析，但必须与正式 resolved 统计分开。

### 2.4 Growth-rate analysis

对于具有足够 onset 后采样数据的运行，在不同后期时间窗口拟合：

\[
\log\sigma(t)
\]

与时间的关系，估计有效增长斜率。

至少比较不同窗口长度，并检查：

- 增长是否持续；
- 是否只是噪声波动；
- 是否出现增长加速或减速；
- 是否存在先增长后衰减；
- 是否出现接近数值精度下限导致的不稳定比值。

如果部分运行保存了 Fourier amplitude 或 mode projection，也应与 sigma 结果对照。

报告拟合窗口选择、数据点数及其敏感性，不将这种拟合直接称为真实 LSA 特征值或非线性增长率。
