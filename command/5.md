## Research objective

继续研究：

本轮目标是开发和验证一种低成本二维 DuMux 计算方案：

**Single-wavelength reduced-domain simulation for evaporation-driven density instability and nonlinear salt transport.**

我们的目的是判断：在均质土壤、横向均匀边界条件和单模态初始化下，能否用一个扰动波长的二维计算域，替代包含多个重复波长的大宽度计算域，从而显著降低后续长时间非线性模拟成本。

本轮不是为了立即找到 transport-effective onset，而是首先验证：

1. 缩域模型是否保持原始物理波数及控制方程；
2. 缩域结果能否再现完整二维 DuMux 的扰动增长和平均盐输运；
3. 是否能显著降低计算时间；
4. 缩域方案适用于哪些物理阶段，以及何时必须恢复完整二维模型。

允许连续完成开发、短窗口测试、结果分析和必要的有限规模模拟，不需要每完成一项就停止等待确认。

不得修改 Paper 1 冻结结果，不得覆盖已经完成的 Case 36877 完整二维基准。

## Task 1 — Mathematical equivalence and boundary-condition audit

先分析当前 `model/transport_v1` DuMux 实现，确认单波长缩域的数学基础。

原始模型：

- Domain width W=0.6 m
- Domain height H=0.2 m
- Grid 600×200
- Initial mode nx=28
- Perturbation amplitude 1e-6
- Eigenprofile initialization
- Lateral no-flux boundaries
- Bottom Dirichlet and top evaporation boundary

初始扰动：

\[
x'(x,z,0)=\varepsilon A(z)\cos(2\pi n_xx/W)
\]

将横向计算域缩小至：

\[
W_r=W/n_x
\]

并使用：

\[
n_{x,r}=1
\]

要求严格检查：

\[
2\pi n_x/W=2\pi/W_r
\]

即物理波数保持不变。

对于 Case 36877：

\[
W_r=0.6/28=0.0214285714286\ \mathrm m
\]

注意：原模型采用侧面 Neumann 边界，不是周期边界。

请证明或数值检查，对当前 cosine 初始化和均质横向边界条件，缩域端点是否满足所需的对称/无通量条件。

不能简单将 Neumann 与 periodic boundary condition 视为等价。

需要明确：

- 缩域是否构成原始完整模型的对称子空间；
- 原始场周期重复后是否满足全部边界条件；
- 是否会排除长波扰动、对称性破缺及跨波长 finger merging；
- 缩域内允许哪些扰动模态；
- 在非线性阶段，该对称性是否可能受到其他扰动破坏。

输出：

`MATHEMATICAL_EQUIVALENCE_ZH.md`

如果发现关键物理或边界不等价，必须先报告，不允许直接将缩域结果视为原始模型的替代。

## Task 3 — Fix domain-size-dependent diagnostics

这是重要的验收任务。

当前 DuMux 的部分表面统计使用节点算术平均和节点标准差。

改变横向单元数量后，边界节点在统计中的权重可能发生变化，导致相同的周期浓度场出现不同的节点平均值或标准差。

因此，不能直接将 R24、R48 的原始 `sigmatop` 与完整600×200模型的 `sigmatop` 数值相减并声称发现物理误差。

请增加网格一致的诊断：

1. 面积/长度加权表面平均盐浓度；
2. 面积/长度加权表面浓度方差和标准差；
3. 物理波数一致的 Fourier amplitude；
4. 统一归一化的 eigenmode projection；
5. 单位水平宽度的盐库存；
6. 单位水平宽度的守恒面盐通量；
7. 实际局部最大浓度和阈值事件；
8. accepted timestep 和守恒预算残差。

同时保留 Paper 1 的原始 sigma 定义，不修改原始 onset 检测协议。

如果需要比较 Paper 1 风格的节点标准差，应通过经过验证的网格映射或者统一统计约定，单独区分采样差异与物理差异。

必须检查缩域 M1 的初始盐库存与 M0 是否一致，不能因为边界节点重复计数而产生虚假的新增盐库存。

## Task 4 — Short-window numerical validation

不要立即开始长时间模拟。

首先使用现有完整二维计算作为 ground-truth numerical reference。

已有完整模型：

Case 36877，600×200，nx28，M0/M1均完成至136423.064 s。

第一阶段新缩域运行终点建议取：

\[
T_{\mathrm{short}}=68211.531886\ \mathrm{s}
\]

约为完整基准的一半，覆盖此前检测到的 \(t_{\mathrm{detect}}\approx50394\ \mathrm{s}\)，同时保留少量后续增长阶段。

执行：

- R24-M0
- R24-M1
- R48-M0
- R48-M1

全部从t=0启动，采用相同物理时间窗口。

短窗口内逐接受步记录诊断，并保存足够的二维场用于空间核验。

与完整模型的对应时刻比较：

- 表面平均浓度；
- 相对和绝对标准差；
- Fourier amplitude；
- eigenmode projection；
- 垂向平均浓度剖面；
- 不同深度的横向扰动强度；
- 单位水平宽度的盐库存；
- 选定控制面上的守恒盐通量；
- 局部最大浓度；
- 守恒残差。

特别注意：

完整域网格宽度与缩域网格宽度不同，节点不一定处于相同物理位置。

如需逐点比较，应将缩域解按其物理波长复制到原域，并使用明确的保守映射或经过检验的插值方案。

不能通过直接比较不同编号的节点来评估误差。

优先比较网格无关的面积积分量、物理波数投影和相同高度的浓度剖面。

由于短窗口可能不足以完整解析 Paper 1 的 onset plateau，不能将短记录内未满足 resolved 分类直接视为缩域模型失败。

## Task 5 — Quantify numerical accuracy and actual speed-up

请记录每一条模拟：

- Actual wall time
- CPU time
- Peak memory
- Number of degrees of freedom
- Accepted time steps
- Newton iterations
- Linear solver iterations
- Failure/rejected steps
- Disk and output sizes

计算：

\[
S=\frac{T_{\mathrm{full}}}{T_{\mathrm{reduced}}}
\]

但必须使用相同计算硬件或经过说明的公平运行环境。

不同服务器的耗时不能直接作为算法加速比。

同时比较 R24 与 R48 的结果。

在运行前登记合理的初步精度标准，至少检查：

- 背景平均浓度和库存误差；
- 模态幅值与增长趋势；
- 所有输出预算的守恒闭合；
- 原始三个控制面的通量差；
- 24到48单元加密后的变化；
- 是否出现非物理的横向结构；
- 最终选择的模型是否足够精确且有实测加速。

不能只要求两种模型的 G_end 接近，就认为物理输运已经验证。

尤其需要区分：

A. 单条平均盐通量误差；

B. M0–M1 配对额外通量误差；

C. 真实额外通量本身低于数值可分辨水平。

若某个参考差值已经处于残差量级，应报告 unresolved，不得用相对误差除以接近零的参考量后做无意义比较。

## Task 7 — Determine the validity domain of the reduced model

综合数学审计和实际计算，明确缩域模型的适用范围。

至少区分：

1. Early linear perturbation growth；
2. Weakly nonlinear single-mode development；
3. Significant convective salt transport；
4. Multi-mode competition and finger merging。

对于第一、第二阶段，如果缩域和完整模型一致，可以允许作为快速候选筛选方法。

对于第三阶段，需要根据实际非线性结果判断是否仍具有代表性。

对于第四阶段，除非额外验证，否则不能声称单波长模型能够代替完整二维域。

提出未来的 full-domain fallback 条件，例如：

- 明显的模态竞争；
- 大尺度横向不均匀性；
- finger merging；
- 缩域与完整域结果出现显著分歧；
- 单波长对阈值时间的预测不稳定。

这些是受限模型适用性判断，不应被当作已经验证的通用物理阈值。
