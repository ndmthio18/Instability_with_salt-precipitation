# P2-A verification evidence

All tolerances were registered in
`model/p2_a_prat_surface/verification/config/acceptance_criteria.json` before
the runs. 61 tests in `verification/test_p2a_surface.py` pass. Evidence tables
are regenerated by `verification/run_verification.py` into
`model/p2_a_prat_surface/results/p2a_verification/`.

Reproduce:

```bash
cd model/p2_a_prat_surface/verification && python -m unittest test_p2a_surface
```

```bash
cd model/p2_a_prat_surface/verification && python run_verification.py
```

```bash
cd model/p2_a_prat_surface/verification && python drive_from_p1r2.py
```

No tolerance below validates physics. They bound implementation and
discretisation error only.

The trajectories are integrated at full resolution; only the committed
trajectory CSVs are thinned by `OUTPUT_STRIDE = 20` (activation steps and final
steps are always kept). Budgets, convergence orders and every number quoted
here are computed on the unthinned integration.

## 4. Crust height evolution (item 10.4)

Tables: `trajectories.csv` (4000 rows), `time_step_convergence.csv`.

* **Exact analytic case.** In the large-`Da` form `v_s` is independent of `h`
  (because `Da*` is), so `h(t) = h0 + v_s t` exactly. The integrator reproduces
  it to < 1e-12 relative over 400 steps.
* **Finite-`Da` case.** `v_s` rises monotonically with `h` and stays strictly
  below the large-`Da` value at every height.
* **Time-step convergence** against a `dt = 12.5 s` Heun reference over
  2e5 s:

| scheme | observed orders (dt 3200 -> 200) | registered minimum |
|---|---|---|
| explicit Euler | 0.993, 0.999, 1.000, 1.000 | 0.9 |
| Heun | 1.990, 1.999, 2.001, 2.004 | 1.8 |

* Height is strictly monotone under evaporation.

## 5. Water and salt mass balances (item 10.5)

Table: `budgets.csv`. Four cases (two interface options x two growth laws),
2e5 s at `dt = 200 s` with Heun.

| case | salt residual (rel) | water residual (rel) | final `h` [m] | quasi-steady storage gap (rel) |
|---|---|---|---|---|
| soil_top \| finite_da | 1.14e-15 | 1.34e-14 | 1.2313e-4 | 8.87e-5 |
| soil_top \| large_da | 1.26e-15 | 1.24e-16 | 1.4960e-4 | 1.49e-3 |
| crust_top \| finite_da | 4.60e-15 | 1.37e-15 | 1.2301e-4 | 9.53e-5 |
| crust_top \| large_da | 1.91e-15 | 5.40e-14 | 1.4946e-4 | 1.48e-3 |

Registered tolerance for both: 1e-10. Budgets also close under time-step
refinement at `dt` = 1600, 400 and 100 s.

**Across the activation event.** Running from an inactive patch through a
declared seed event and on to 2e5 s, the salt and water budgets still close at
1e-15 level, with the seed inventory reported explicitly
(`seed_salt_kg_m2`, `seed_water_kg_m2`). This was a real defect found during
verification: the first implementation created the seed inventory without
charging it to the soil, giving a 26 % salt-budget residual, i.e. precisely the
behaviour item 8 forbids. It is fixed and now covered by a test.

Other balance checks:

* `F_s,soil` equals the increase of `M_s,solid + M_s,d` to 1e-15;
* `F_w,soil = rho U(0) - F_s,soil` and
  `F_w,soil = j - rho_v v_s + dM_w,c/dt` agree to 1e-13;
* `rho U(0) = rho U(h) + R_int` to 1e-14;
* the two base-flux routes differ by exactly the closed form
  `-(eps_c S_c rho C*_top + C_eq rho_v) v_s`, to 1e-12 of the flux scale;
* total solid always exceeds the pure skeleton mass, by the internal reaction.

## 7. One-way diagnostic chain driven by P1-R2 (item 7)

Script: `verification/drive_from_p1r2.py`. Output:
`results/p1r2_driven_chain/`.

**Declared inconsistency.** The P1-R2 salinity histories were produced with a
fixed prescribed evaporation flux. This module computes a salinity-dependent
flux. The two atmospheric boundary conditions differ, the film flux is not fed
back, and nothing below is a coupled result.

| P1-R2 run | soil `w_NaCl` range | `a_w` range | film flux decline | fraction of `C_eq` reached | seed fired |
|---|---|---|---|---|---|
| V5 Mode A 1D (1201 records, 0-136423 s) | 0.011585 -> 0.060482 | 0.99335 -> 0.96338 | 5.08 % | 22.83 % | no |
| V5 Mode B 1D | 0.011585 -> 0.063127 | - | 5.37 % | 23.83 % | no |
| V8 Case 36877 R24 2D (601 records) | 0.011585 -> 0.060481 | - | 5.08 % | 22.83 % | no |

**Result: no crust forms on any committed P1-R2 trajectory.** The soil surface
reaches at most 23.8 % of halite equilibrium within the frozen window, so the
declared seed event never fires and the chain terminates at the evaporation
flux. The 5.1 % flux decline over the window is the salinity feedback that
item 4 requires to be visible; under the legacy prescribed boundary it is
identically zero by construction.

To exercise the remaining links, a **declared synthetic** soil-concentration
ramp (initial Case 36877 value to `C_eq` over 1e5 s, then held for 4e5 s) is
run as a clearly separate case. It is not a solution of the Richards-salt
problem. Representative result (soil_top, finite_da):

| quantity | value |
|---|---|
| activation / eligibility time | 1.0e5 s (identical, both recorded) |
| `h`: 1.000e-4 -> 1.5038e-4 m | growth factor 1.504 |
| final `j` | 1.7815e-5 kg m^-2 s^-1 |
| final `v_s` | 1.4681e-10 m s^-1 |
| final `F_s,soil` | 1.3625e-6 kg m^-2 s^-1 |
| final `F_w,soil` | 1.7867e-5 kg m^-2 s^-1 |
| final `C*_top` | 1.3221e-3 |
| final `Da` | 0.438 |
| salt / water budget residual | 8.1e-16 / 9.4e-15 |
| `pe_much_smaller_than_da` | **true** |
| `large_da_valid` | **false** (`Da < 10` at this height) |
| `constant_porosity_defensible` | **false** |
| internal/top precipitation | 6.05 |

The full chain therefore runs end to end and conserves, but at the declared
parameters the crust sits in the finite-`Da` regime with internal precipitation
dominating top growth, so the constant-porosity assumption of the reduced
solution does not hold. See `P2_A_SURFACE_MODULE.md` section 7.1.

## 8. What this evidence does not establish

1. No parameter here is measured. `a_v`, `k_r`, `eps_c`, the seed height and
   the film thickness are declared inputs, so every absolute rate is
   parameter-conditional.
2. Nothing has been run against a live Richards solution. The chain is one-way
   by instruction.
3. The module is Python. A DuMuX C++ port has not been written or compiled.
4. Conservation of the subgrid does not validate the Prat closure, the film
   closure, the activation rule, or the no-lateral-transport approximation.
5. The constant-porosity tension of section 7.1 of the module document is
   unresolved and is a gate on any coupled run.
