# 方法

## 研究边界

本任务是数值机制审计，不修改 Prat 顶部生长律、ALE 内部反应、`k_r`、`a_v`、扩散系数、界面浓度耦合、气膜蒸发或孔隙率上下界。诊断器只观察已接受状态；唯一求解器改动是增加与 BDF 同步积分的通量/反应附加状态。

## 算例

- 历史机制参考：旧 xNaCl=0.08 adaptive-multilayer，直接读取 HPCC 原始逐单元状态。
- 同方案对照：xNaCl=0.08 progressive，N80、ALE64、dt=0.5 s。
- 主实验：xNaCl=0.09 progressive，N80、ALE64、dt=0.5 s、TEnd=25000 s。
- 时间步检查：相同 xNaCl=0.09 条件，dt=0.25 s。

主实验中 `Problem.SaltMoleFraction` 同时控制初始土壤和 reservoir；后处理中读取 `reservoir_config.csv` 独立验证配置值、reservoir 值及已接受初始场最小/最大值均为 0.09。

## 独立通量重构

`analyze_flux_mechanism.py` 不调用 C++ `ALE::flux()`。它从 `ale_diagnostics.csv` 的 `epsilon`、`C`、实际物理面位置、`h`、界面浓度和蒸发通量重新实现：

1. `D_eff`、`a_v` 和有符号反应；
2. 顶部二次根与生长速度；
3. 自顶向下液相质量通量递推；
4. ALE 网格运动通量；
5. 内部面迎风对流与串联扩散阻力；
6. 底部对流/扩散通量；
7. 独立的顶部固体生长通量。

重构值与生产诊断中的反应、`D_eff`、`a_v`、生长速度及底部液体/盐/对流/扩散通量逐状态比较。密度由每个状态保存的孔液盐库存反算，不假定为任意常数。

## 时间与空间选择

空间剖面选择最接近激活后 0、0.5、1、2、5、10、30、100、200、300、400、500、800、1200 s 的实际接受态，并增加最后接受态、首个拒绝态和实际达到的孔隙率事件。超过提前停止时间的目标不插值、不外推。

x=0.08 与 x=0.09 同方案对照采用两类匹配：共同激活后历时，以及共同可达高度范围内的匹配高度。旧 adaptive 结果只作机制参考，不用于把差异归因于盐度。

## HPCC 执行

- 构建：Slurm `16445808`，8 CPU，compute node；独立 BDF 局部守恒单元测试后完整编译 DuMux。
- 求解数组：Slurm `16445813`，三个独立算例并行，每例 2 CPU。
- 后处理：Slurm `16445845`，4 CPU，依赖求解数组完成后启动。

所有编译、求解和绘图均在 Slurm compute node 上完成。登录节点仅用于传输、校验和、提交和只读状态检查。
