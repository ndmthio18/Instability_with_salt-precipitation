# P2-H 盐壳内部通量机制与 xNaCl=0.09 审计报告

## 结论先行

本轮对**当前方程的数值机制审计为 GO**：ALE 面通量可独立重构，接受步局部/累积/整壳盐预算闭合，x=0.09 输入被实际场验证，dt 减半结果一致，底溶—顶长及中部反向扩散衰减可以由当前离散方程完整解释。

但对“该机制已经是可定量外推的真实盐壳物理”仍为 **NO-GO**。当前界面闭合没有显式描述底部固相接触平衡、固体耗尽或界面退缩；守恒和时间步收敛只能证明当前数学模型自洽，不能证明其溶解强度真实。

## 直接验证事实

### 1. 输入与运行

主算例的配置、reservoir 值和已接受初始场最小/最大 NaCl 摩尔分数均为 `0.09`。没有只改 reservoir 或只改初值。

| 量 | x=0.08 progressive | x=0.09 progressive |
|---|---:|---:|
| 首次表面析盐 | 19048.5 s | 4314.5 s |
| ALE 激活 | 23136.0 s | 6745.0 s |
| 最后接受时刻 | 23637.213926 s | 7382.770656 s |
| 激活后历时 | 501.213926 s | 637.770656 s |
| 最终几何高度 | 5.219784 µm | 5.703802 µm |
| 最终固体等效高度 | 4.132248 µm | 4.832684 µm |
| 最终 `epsilon_min / epsilon_max` | 0.190230 / 0.950000 | 0.171941 / 0.950000 |

两例都不是完成到 25000 s，而是在底部孔隙率达到既有上界 `0.95` 时停止。x=0.09 只覆盖激活后 637.77 s，因此没有伪造 800 s 或 1200 s 场。

dt=0.25 s 的 x=0.09 对照在 7382.503828 s 停止，激活后历时 637.753828 s，最终高度 5.703189 µm。与 dt=0.5 s 在共同末态附近相比：高度相对差 `9.48e-5`，顶部生长通量相对差 `7.75e-7`，溶解率相对差 `4.62e-5`，`epsilon_min` 绝对差 `5.88e-6`。提前停止不是粗时间步产生的假象。

### 2. 通量重构与守恒

独立 Python 实现没有调用生产 `ALE::flux()`；它从逐单元状态和实际面几何重建移动网格、对流、扩散、反应和顶部固体生长。所有四组数据均通过“绝对误差 `<=1e-18` 或相对误差 `<=1e-10`”的逐量门槛。接近零的激活初始扩散通量会使纯相对误差病态，因此没有用单一相对门槛误判。

x=0.09 主算例的 BDF 接受步积分守恒最坏值为：

- 单元：`8.97e-20 kg/m²`，相对 `4.45e-9`；
- 从底部到任意单元的前缀累积：`1.35e-18 kg/m²`，相对 `4.84e-8`；
- 整壳孔液：`1.34e-18 kg/m²`，相对 `4.26e-8`。

最后的相对峰值来自净变化尺度接近零；绝对残差保持在 `1e-18 kg/m²` 量级。全耦合历史中，最大盐/水残差分别为 `6.70e-16 kg` 和 `2.73e-15 kg`，相对初始库存约为 `2.84e-14` 和 `3.72e-14`。

### 3. 反向扩散衰减的来源

旧 x=0.08 adaptive 末态重现了任务给出的数值：底部扩散为 `-3.561e-6 kg m-2 s-1`；在 `z=3.985 µm` 降至底部幅值的 `0.04713`，即约 `-0.168e-6 kg m-2 s-1`。

该 `0.04713` 可分解为：

- 浓度差比 `0.4925`；
- 精确离散扩散电导比 `0.09570`；
- 二者乘积 `0.04713`。

同处 `epsilon^(3/2)` 比为 `0.09168`，与电导比接近。因此，末态衰减不是“反应在某个面直接截断通量”，而是反应造成的浓度场与沉淀造成的低孔隙率传输阻力共同作用；在该快照上，孔隙率/电导效应比梯度效应更强。

x=0.09 末态更明显：扩散最小位于 `z=4.187 µm`，幅值比 `0.02369 = 0.3066 × 0.07728`，对应 `epsilon^(3/2)` 比 `0.07890`。该位置与第一反应变号位置 `4.205 µm` 接近，但这种空间共定位本身不是独立因果实验。

### 4. 完整盐速率分解

x=0.09 最后接受态（单位均为 `1e-6 kg m-2 s-1`）：

| 量 | 值 |
|---|---:|
| 顶部固体生长 `G_top` | 4.3230 |
| 内部正沉淀 | 2.0095 |
| 内部溶解幅值 | 3.6558 |
| 内部净反应 `R_net` | -1.6463 |
| 孔液盐库存变化 `dQ_pore/dt` | +0.7219 |
| 土壤净供盐 `J_s,bottom` | 3.3986 |

守恒关系为 `3.3986 = 4.3230 - 1.6463 + 0.7219`。因此顶部增长超过土壤净供盐的部分，确由**内部净溶解和孔液盐储存变化共同解释**；不能写成“顶部增长减底部溶解等于供盐”。

底部对流输盐为 `+6.1509e-6`，反向扩散为 `-2.7523e-6`，净供盐才是 `+3.3986e-6`。末态溶解区厚约 4.187 µm，上部正沉淀区约 1.516 µm。

`G_top/[Ceq*j/(1-Ceq)] = 0.6732`。这个分母只作为饱和盐水蒸发参考，不是普适生长上限。

## x=0.08 与 x=0.09 的受控比较

在共同激活后约 501 s，而非各自末态直接比较：

- x=0.09 的底部欠饱和从 x=0.08 的 `-7.52e-6` 减弱到约 `-5.40e-6`；
- 反向扩散由 `-3.554e-6` 减弱到约 `-2.783e-6`；
- 内部溶解由 `4.611e-6` 降到约 `3.645e-6`；
- 两者盐层高度都约为 5.22 µm。

因此提高初始及 reservoir 盐度系统性减弱了底部欠饱和、反向扩散和溶解，但没有消除底部孔隙率增长到 0.95 的停止机制。

## 假设判定

| 假设 | 判定 | 证据边界 |
|---|---|---|
| H1 下部溶解是反向扩散的重要来源 | **Supported（对当前方程）** | 溶解区、负反应、向下扩散和接受步局部预算在全过程一致；仍非实验验证。 |
| H2 扩散最小由反应梯度与孔隙率反馈形成 | **Partially supported** | 梯度比与电导比的乘积定量重建衰减，位置与反应变号接近；未做关闭反应/固定孔隙率的独立因果消融。 |
| H3 `h/ell` 可预测反应区分布 | **Partially supported** | 局部尺度随分区系统演化，但底部 `h/ell` 从 4.49 降至 1.20，而中值 `h/ell` 升至约 8.63；不存在一个可替代全场的单值预测量。 |
| H4 x=0.09 系统改变欠饱和与溶解 | **Supported（数值模型内）** | 同初始化方案、同高度/同历时比较均显示欠饱和、反向扩散和溶解减弱。 |
| H5 顶部长得更快可由溶解与库存共同解释 | **Supported** | BDF 接受步及全局预算直接闭合。 |
| H6 缺失界面闭合仍可能造成过度溶解 | **Partially supported** | 代码确无固相接触/耗尽/退缩闭合且两盐度均持续溶解；本任务未提供替代闭合或实验数据来量化“过度”。 |

## 科学决策与下一步

优先级应是**界面闭合，而不是继续调内部反应参数**。内部反应–扩散算子已经表现出高精度守恒、面通量可复现和时间步稳定；当前最关键的未识别物理位于土壤–盐壳底部：何时维持饱和平衡、底部固体如何被耗尽、是否允许界面退缩，以及这些过程如何限制溶解通量。

建议下一阶段建立一个保守、可关闭的界面固相库存/平衡/退缩最小闭合，并用相同 x=0.08/0.09 算例做消融。只有其参数能由实验或独立微观模型约束后，才值得重新标定内部 `k_r` 或 `a_v` 并提出定量物理结论。
