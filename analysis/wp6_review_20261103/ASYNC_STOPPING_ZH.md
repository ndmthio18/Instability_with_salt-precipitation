# 异步溶解度停止与配对接口

新接口 `scripts/wp6_paired_stopping.py` 先独立核验各腿，再匹配共同时间。旧生成器和旧结果保留；后续应使用 `scripts/analyze_wp6_review.py`，不再使用旧脚本中要求同长度/同 dt 的验收逻辑。

## 验收语义

- 每条腿独立检查：退出码、初始帧、连续接受步号、严格递增且有限的时间、正 dt 与时间递推、浓度最大值及阈值标志、停止理由、首次事件区间和最后接受步。可接受不同 dt、不同终止时间和不同样本数。
- 只有两腿已有的共同接受状态进入守恒比较。允许 32 个 binary64 ulp 的文本表示容差，**不使用时间分箱、重采样、插值或外推**；返回实际误差及两腿索引。不同求解网格的累计时间漂移若大于此界限便不匹配，应设计共同输出锚点，不能放宽到物理时间容差。
- 单腿到窗仅容许 ≤1e-7 s 的数值终点差，保留实际接受时间；此容差不参与共同时间匹配。dt/2 对照实际少于目标 1.16e-8 s，属于此情形。
- 取两腿首次阈值 crossing 的较早 high 为截止值，排除该帧及之后所有状态。上一个未 crossing 的接受状态可保留。t=0 已 crossing 时共同物理窗口为空，状态为 `insufficient_common_prethreshold_states`，不是求解器失败。
- 对每个控制体检查预算时刻与本腿事件时刻一致、库存/累计量有限，保留初始库存差修正；各腿盐水收支独立通过后才比较。

## 事件与删失

表面事件与任意局部事件分别报告。全域最大值包含表面：只有 global crossing 且 surface 尚未 crossing 才能称为 `interior_first`。若表面先 crossing，全域标志同时触发并不能证明内部也 crossing；现有记录没有独立排除表面的内部最大值，这时内部事件返回 `not_separately_identifiable`。不虚构内部阈值时间。

一般观测区间为 (l,u]，初始事件为 [0,0]。记 Δτ=τ_M1−τ_M0：

| 情况 | 可报告结果 |
|---|---|
| 两腿同一事件都观测到 | 保守包络 [l1−u0, u1−l0]，端点开闭按原 crossing 区间解释 |
| M0 观测、M1 在 c1 仍未观测 | Δτ > c1−u0，上界未知 |
| M1 观测、M0 在 c0 仍未观测 | Δτ < u1−c0，下界未知 |
| 两腿都删失 | Δτ 不可识别，不能给 0 或有限区间 |
| 一腿内部先到、一腿表面先到 | 可比较任意局部事件，但不能称为表面延迟；表面仍按各自观测/删失处理 |

内部先触阈值而停止时，表面时间是在适用性终点被删失；未来是否存在表面事件亦未证明。所有单边时间差解释都以该事件在后续适用模型中存在为条件。两腿当前 2T 均右删失，既不能证明 M1 延迟，也不能证明其提前。

## 测试与回归

17 项单元测试覆盖 M0 先到、M1 先到、不同窗双删失、不同事件类型、自适应非重叠时间、单边界、t=0 crossing、排除 overshoot 帧、错误停止理由/区间/退出码、重复时间/坏 dt、crossing 后继续计算、近似却不同的时间、不改变实际时刻的终点容差及缺失预算。另有 5 项合成 CSV 端到端测试，将 M0先到、M1先到、双删失、事件类型不同和空共同窗口传入完整新后处理器；这些是接口测试，不冒充物理模拟。

对原 2T 的 1,201 个共同接受状态、8 个控制体共 9,608 行，所有旧数值字段和候选标志**完全相同**，最大绝对差 0；`frozen_2T_parity.json` 锁定旧 CSV SHA。1e-7 终点容差没有用于此回归的共享时刻。

未来已归档运行可显式指定：

```text
python scripts/analyze_wp6_review.py --m0 <M0目录> --m1 <M1目录> --out <本仓库analysis下的新目录>
```

自定义输出必须不存在；完整 `finished.json`、事件、预算、独立检查和相同面坐标是输入条件。该程序只后处理，不能提交模拟。原 command/7 的 `same_accepted_time_series` 不再是异步配对的成功条件。
