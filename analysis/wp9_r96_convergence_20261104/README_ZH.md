# WP9 R96 网格敏感性与 LSA–DNS 模态核验

## 结论先行

本工作包已经完成。R96-M1 在 sal 上完成 9600/9600 步，R96-M0 在用户**单独授权**
`WP9-A02` 后于 hpcc 上用 4 线程完成 9600/9600 步；两条腿均通过全部数值验收。
R48/R96 的冻结判据为 G1、G2 通过，G3、G4、G5 失败，因此机读结论为 **NO-GO**：
4T 时不能提出局部守恒通量机制验证，不能定义 `t_eff`、结晶延迟或代理模型训练标签。

这里的 NO-GO 不是求解器失败。它表示研究设计尚未证明晚期模态、水平平均响应和
1 mm 输运对当前离散选择足够稳定。R96 同时把 `dx` 与 `dt` 减半，因而三分辨率结果
不能给出纯横向空间收敛阶；`nz=200` 从未改变，盒宽又排除了 LSA 全局临界模态。

## 不得越界的解释

1. 4T 前没有局部溶解度穿越；`T_sol > 4T` 是右删失，不是“不会析出”。
2. 小扰动窗内 LSA 与 DuMuX 增长率相差 4.2%–9.8%，支持的是数值模型的线性阶段一致性，
   不是实验验证，也不是晚期输运或形态验证。
3. 4T 的 m=10 能量随网格显著下降，冻结判别归为 `noise_seeded`；R96-M0 又表明细网格
   总噪声能量不再按同一速率塌缩。因此更准确的物理解读是：分辨率相关种子被真实线性
   不稳定放大，而不是已经证明的非线性级联。
4. 本工作包没有启动 R192、多波长、全域或 8T，也没有重试任何生产腿。
