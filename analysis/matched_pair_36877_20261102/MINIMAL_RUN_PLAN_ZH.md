## C. 为什么现在不需要独立1D求解器

目的首先是隔离“是否允许横向初始扰动”对同一数值系统的影响。现有M0使用同物理、同网格、同残差的均匀二维，已检查所存13帧横向均匀性及预算，足够作为当前严格配对参照。它不是数学上强制横向不变的1D模型：若延窗后噪声增长，就不能继续把它当作抑制对流的背景。

独立1D是后续降本或背景保持机制的选项，不是当前启动唯一M1之前必须完成的软件项目。要引入它，必须对同垂向网格、同输入的剖面/库存/通量/阈值区间做等价性检查。没有这些证据，不把“uniform 2D”改称“已验证1D”。

## D. 若未看到可分辨的额外输运

按以下顺序作决策，避免无休止延长或换样：

1. **ΔC与误差相当，或闭合失败：** 先处理残差、时间对齐、切面与网格误差；结论是数值未分辨，不能判定物理零效应，暂不延窗或换案例。
2. **误差足够小，但扰动仍缓慢增长且双方远离0.1：** 可提出双方共同延长窗口，先估计可用增长时间和成本，设置预先固定的新终点；不只延M1而外推M0。当前程序没有经验证的状态重启路径，不能只将TEnd改长并假定续算可靠；可从t=0重跑两条到新终点，或先验证重启和累计预算衔接，均须另行确认。
3. **M1已明显增长但ΔC仍小、可靠且深度传播弱：** 这是“可检测失稳未必产生显著再分配”的候选结果。先看adv/diff补偿、C0/C1净方向、表面响应和窗口限制；允许有界延窗验证，但不因已有onset就预设必有强输运。
4. **可用窗口内无持续增长，或任一方已达溶解度阈值：** 不继续过饱和无沉淀计算。复查profile匹配、闭合分支和LSA所对应背景；再从联合物理支持中选一个预阈增长更快的候选做完整配对。现有case42929无扰动运行只能辅助筛选，不能单独作为输运证据。
5. **有控制的延窗/第二候选仍无稳健信号：** 重新评估“自然幅值扰动能在溶解度前产生有意义再分配”的物理假设及Option A研究问题，记录有限窗口的负结果；不扩大DoE或用机器学习弥补缺少物理目标。

改幅值、改模态、改初始区域可作为独立的扰动侧研究，但须另注册，不能把它们混入本主协议而宣称其物理结果得到验证。

## E. GO / NO-GO

- **现在：** GO仅指已准备好一条待授权M1；NO-GO适用于自动启动、扩展完整Pilot A/B、物理有效性结论和代理模型。
- **第一条M1之后：** 若来源/初始场/共同窗口/守恒通过，GO进入最小敏感性；若失败，先修复证据链。
- **敏感性之后：** 只有配对信号、误差分辨、表面/库存物理后果和观测深度稳健性均有证据，才讨论是否扩展。单case通过仍不证明跨土壤普适规律或满足期刊创新性要求。
