# Pilot-0 配对输运诊断约定

版本：2026-11-02。适用范围：case36877，同一Paper2 ELF、指数krw、串行BOX、顶部/侧面零盐通量。这里只定义连续诊断与误差评估，不定义t_eff。

## 1. 守恒量、符号和初始差

对每条运行j=0,1、每个上部控制体r：

`I_j,r(t) = (1/W) Σ_(SCV∈r) phi Sw x V_SCV`，单位m。

`Q_j,r` 为该控制体底面向下为正的总盐面通量，单位m/s；保留adv、diff和total。所有量来自求解残差共享的面通量函数，禁止以VTK cell-centre velocity×x代替。

`C_j,r(t_n) = Σ_(k=1..n) dt_j,k Q_j,r(t_j,k)`。

采用**实际接受步末**通量，即隐式Euler预算；不是梯形积分，不用指定dt替代降步后的dt。t=0行不贡献累计量。当前顶部/侧面盐通量为0，故

`R_j,r(t) = I_j,r(t) - I_j,r(0) + C_j,r(t)`。

对配对：

`ΔC = C_1 - C_0`；

`D_I = [I_1(t)-I_0(t)] - [I_1(0)-I_0(0)]`；

**`D_I + ΔC = R_1 - R_0`**。

验证时同时保存左侧闭合量、两条运行各自残差、右侧残差差，以及代数误差 `D_I+ΔC-(R1-R0)`。后者接近舍入只说明读取和差分正确；真正数值误差还取决于每条运行残差与敏感性。不能把库存反算C后再次用该公式声称获得独立通量验证。

固定参考量 `I_ref,r=I_0,r(0)>0`，报告ΔC/I_ref和D_I/I_ref，不随时间重设分母，不取可能趋零的ΔC作为唯一归一化尺度。当前是归一化组分库存，未乘摩尔密度，不能把单位改成kg或mol。

ΔC>0、D_I<0：M1相对M0减少上部积累；若C1仍<0，必须描述为减少净向上供应，不能宣称发生累计净向下转移。adv/diff分量用于判别补偿关系；“额外总输运”不等于单纯扰动相关对流。

## 2. 时间、阈值与观测面

- 主配对必须在共同的实际时间、实际BOX控制面比较。三个实际z/H为0.899515406020609、0.7522817588955184、0.500531905678623，对应深度H−z约20.097、49.544、99.894 mm。
- 当前后处理器对时间错配或实际切面错配直接拒绝；不把不同时间索引当成同一时刻，不静默插值。
- 若M1被Newton降步，输入相同仍不意味着时间协议完全实现一致。先保留两条实际步序；优先在双方真实共同接受时刻比较。若共同点不足，冻结可复现的共同步序后重跑所需参考解；如另开发保守分段末值累计对齐，须显式带上对齐误差，不能作为本脚本的隐式行为。
- 比较窗口截止于双方较早的终点或任何一方全域/表面首次阈值事件的最后安全接受步。首次跨阈值行只用于记录事件区间，排除于无沉淀物理结论；不对未观测到事件的结束时刻伪造事件时间。
- 表面浓度同时输出面积加权均值、节点最大值；保留全域最大值防止内部先越界。标准差固定为顶部节点标准差，同时保留原 `*_sigmatop.csv` 的Fourier和mode projection；若需跨运行比较模态幅值，应对两条场用同一nx28基底重投影，M0内置Constant分支的投影不能冒充nx28投影。
- ΔC为累计量，需同时呈现C0、C1、ΔC、D_I、表面均值/极值和sigma。不得仅截取最有利的一个深度或时刻。

## 3. 误差预算

对每个共同时间和深度，预先分项记录：

| 项 | 估计方法与限制 |
|---|---|
| U_budget | `abs(R1)+abs(R0)`，不依赖配对残差偶然抵消；同时检查逐步残差有无突增 |
| U_round/IO | 独立VTU库存、求和顺序与序列化核验的实际偏差。本例初始三深度达到8.57e-17 m量级；M1产生后重算，不能以1e-26抵消余量当精度 |
| U_dt | 同物理、同profile、同网格的两套**配对差值** `abs(ΔC_dt/2−ΔC_dt)`；同步检查D_I和表面量。单次减半是敏感性，不是已知收敛阶的误差界 |
| U_z | 匹配物理截面后，Nz200/400两套配对差值之差。若不单调、符号变或差异接近信号，追加800级或调整离散方案，不做无依据Richardson外推 |
| U_cut | 分级网格加密导致实际切面移动的影响；必须单列，不能将不同控制体的差异全部归为网格误差 |
| U_align | 若采用非共同接受时刻映射，需要对齐方案变化或共同步序参考的差异；当前严格脚本拒绝这种情况，因此相同步序时为0 |
| U_x（条件性） | 如出现具有物理意义的横向结构，增加一次横向加密配对评估。600/28≈21.4个单元/波长不是收敛证明 |

初筛使用保守相加的经验包络 `U = U_budget + U_round/IO + U_dt + U_z + U_cut + U_align (+U_x)`；列明各项来源。该包络是工程敏感性评估，**不是严格数学上界或统计置信区间**。未计算项写“未知”，不补0，不宣称已分辨。一次时间和网格加密不能覆盖二者交互；可疑时在细网格上再减半dt。

评估报告连续的 `abs(ΔC)/U` 和各项贡献，检查符号、时间段及各深度的稳定性。可将信号至少为估计包络3倍作为**待审批的保守筛选规则**，但不能将“3倍”称统计显著性，也不能据此生成最早跨阈t_eff。即使数值可分辨，仍须说明库存/表面浓度影响的物理量级；数值可分辨与物理重要性是两个问题。

当前只有M0的预算残差；M1、U_dt、U_z、U_cut均未具备，故不能报告有效输运信噪比。历史不同模态、旧ELF的时间步对照只作方法参考，不能填入本对的误差栏。既有短背景测试的1e-12 m绝对验收下限也不能自动移植为本对的信号门槛。

## 4. 垂向切面一致性是独立门槛

当前C++只输出最接近三个名义高度的BOX面。细网格的“upper_0.9”不保证与粗网格对应相同高度。脚本严格拒绝跨网格直接逐行相减。

在执行网格敏感性前，先完成无求解的网格坐标和观测面预检：保持同一分级映射，避免简单把Cells1改400而保留每格比率-0.98导致整个网格拉伸重新分布。首选按已存顶点坐标构造嵌套细分，并核验底部/顶部单元尺寸；不只检查单元数。

若沿用现有ELF，允许先分别完成每套网格内部严格配对，再用共同保存时刻的场、同物理深度积分估计切面迁移影响，**但此重构仅用于U_cut敏感性，不能冒充同一物理面的独立守恒通量**。仅凭当前三面输出不能保证严谨地界定全时间段U_cut。

若U_cut无法证明远小于信号，必须先扩展诊断到固定参考面及相邻面，并设计使所选面保持为BOX控制面的嵌套网格。可采用每个原区间三等分来保留原中点面，但需允许显式选择原实际切面，不能仍让程序按0.9/0.75/0.5重新选最近面。改动后需新的源码/ELF身份、静态/编译检查和同网格M0/M1桥接验证；旧粗网格结果仍保留，不能混称同一二进制配对。此扩展本次未实施。

## 5. 后处理使用边界

`scripts/analyze_matched_pair.py` 接收已完成运行目录，要求包含实际 `params.input`、`plan.json`、profile（M1）、`finished.json`、`stop_record.json`、预算和表面CSV。验证输入/输出/profile哈希、ELF及源码身份，并拒绝错误模态、初始幅值、参数和切面/时间错配。输出状态始终为“配对诊断待敏感性”，不会自动GO。

当前可复现的真实数据程序检查：

```powershell
python scripts/analyze_matched_pair.py --m0 analysis/unperturbed_36877_20261102/evidence --m1 analysis/unperturbed_36877_20261102/evidence --out analysis/matched_pair_36877_20261102/self_null --diagnostic-only
python scripts/check_matched_pair_diagnostics.py
```

`--diagnostic-only`明确绕过物理配对资格，仅用于M0自身相减等代数检查。它不输出有效输运结论。真实M1产生后，首次分析前还需独立重算其初始场库存并验证本报告预测，保存原sigma/Fourier/模态记录。
