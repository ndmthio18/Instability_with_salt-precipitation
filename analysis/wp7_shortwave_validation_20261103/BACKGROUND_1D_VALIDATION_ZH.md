# 一单元背景解与二维 M0 对照

## 定义边界

本轮“1D”实现是横向仅一个单元、仍求解相同二维方程的一单元挤出背景模型。它与二维 M0 和二维 M1 分开保留，不能把它改名为二维无扰动解，也不能把二维 M0 在晚期的自发横向增长归入 1D 背景。

## 结果

一单元背景完成 1200 个接受步至 1T，独立 VTU 库存复算、七面累积通量重积分及盐/水闭合检查均通过。与 R24 二维 M0 有 1200 个逐位相同的共同时间帧，最后共同时间为 136309.3778859 s；两者名义 1T 末态相差 1.00e-7 s，因此末态不冒充“精确共同时间”。

- 共同时间内浓度均值剖面最大绝对差 3.88e-15，按二维参考全局尺度归一化为 2.00e-13，远低于 1e-6 门槛。
- 盐/水库存最大差分别为 1.33e-17 m 和 2.63e-15 m。
- 七面总盐通量与水通量的最大全局归一化差分别为 1.59e-8 和 8.92e-9；累积盐与水差分别为 1.87e-10 和 1.21e-8。
- 盐/水残差的相对差大于 1，只因为两边残差都接近零；应使用绝对证据。一单元独立检查的最大盐闭合为 2.85e-16 m，最大水闭合为 5.85e-14 m，均通过原绝对闭合门槛。

## 保留的失败

一单元解的最大横向 σ 为 1.945e-14。由于横向只有两个等权端点，横向范围为 2σ，即 **3.890e-14**，超过预登记的 1e-14 绝对门槛。因此总体背景验证判为 **partial / strict uniformity FAIL**，不能写成全部通过。

该偏差处于浮点噪声量级，且远小于剖面/收支尺度，所以它不否定背景方程的一致性；但阈值是结果前冻结的，不能事后放宽。后续应先查清求解容差与 BOX 端点对称性，再决定是否以有理论依据的舍入尺度替代 1e-14，而不是直接重写门槛。

证据：`background_validation.json`、`background_budget_comparison.csv`、`runs/WP7-1D-background-T/`。
