## 七个问题的回答

1. **4T 时扰动增长了多少倍？** 加权表面 σ 为 3.66177e-3，相对全窗最小值 **5514.75 倍**，相对初始 **5178.52 倍**，相对表面均值 **6.49224%**。基频 Fourier 和 A28 投影相对各自最低值分别只增长 128.69、216.22 倍，不能将总 σ 的倍数等同于原基频增长。
2. **是否出现非线性发展或 fingers？** 出现明显的浅层短波条状结构与高次谐波，提示离开极弱单模态状态；但主导 m=10 占异常能量 93.46%，每波长仅 4.8 格，且奇模态/对称性失败。可以报告非线性发展的候选证据，不能确认可信的物理 fingers。99% 能量深度从 2T 的 2.724 mm 降至 4T 的 1.892 mm，没有深部穿透证据。
3. **是否比 2T 有更显著的向下盐再分布？** 相对 M0 的浅层 ΔC 大幅增大：1.029 mm 为 **1.87086e-8 m**，相当于该上部区域初始库存的 **4.81869%**；1.948 mm 为 **4.59661e-9 m**，约 **0.624982%**。但两腿七面末态净通量仍全部向上，正 ΔC 主要表示向上富集减弱，不能写成已经向下净排盐。更深处候选差超出闭合残差，却仍缺少离散误差验证。
4. **有无可靠证据表明对流改变表面富集？** 数值上，M1 表面均值比 M0 低 **0.992636%**，局部最大值却高 **11.333773%**。这是值得验证的竞争信号，尚不是可靠的因果结论：M0 的 σ 已达 M1 的 **5.10519%**，不能继续视为一维无对流参照，短波与 4T 时间/网格/域误差尚未控制。
5. **是否达到溶解度极限？** 没有。M0、M1 的表面及全域最大值分别为 **0.0573408、0.0638397**，均低于 0.1。两个事件均 right-censored，时间差 unidentified，不外推结晶时刻或延迟。
6. **是否继续到 8T？** **NO-GO：先解决背景和短波分辨率问题。** 更多相同网格的模拟时间会继续积累尚无法解释的短波，不能补足验证证据。
7. **是否必须开展多波长验证？** **是，已到了需要该验证的阶段**，但应先完成受控的时间步、横向/垂向网格与背景参照核验，再按同 Δx 设计 2/4 波长及有界完整域抽查。方案已写出，本轮不追加运行。
