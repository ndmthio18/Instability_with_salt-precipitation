# P2-H reservoir 供液修订：开放边界守恒与 50 h 激活门

## 最终结论

本轮完成了开放底边界水盐账本的数值修复，并用真实 DuMuX 计算验证
`reservoir` 确实持续供水；但参考 pilot 在 50 h 内没有达到 NaCl 平衡质量分数，
因此没有表面固体、没有 ALE 激活，也没有可识别的 `k_r/a_v` 响应。按预先声明
门槛，ALE 网格/时间步扩展和五算例矩阵均未运行。最终科学状态是
**FAIL_NO_SURFACE_PRECIPITATION_NO_ALE_ACTIVATION / NO-GO**，而不是程序失败。

## 1. 已实现的数值修复

底部通量以进入 `soil+crust` 系统为正。对最底层 BOX 控制体，在每个接受的
Backward-Euler 终点使用与 DuMuX 残差相同的内部 SCVF 通量算子重建：

```text
B_liquid = (M_bottom,new-M_bottom,old)/dt - F_cut,down
B_salt   = (S_bottom,new-S_bottom,old)/dt - F_salt,cut,down
B_water  = B_liquid-B_salt.
```

累计底部液体/盐库存属于事务化 `SurfaceState`；拒绝的土壤、ALE 或激活尝试
不会计入。检查式改为

```text
M_water,soil + M_water,ALE + M_vapour - B_water,cum = M_water,0
M_salt,soil + M_salt,ALE + M_solid - B_salt,cum = M_salt,0.
```

局部 ALE 反应、固体拆分和初始化转移检查均保留。完整定义见
`model/p2_h_ale_coupling/RESERVOIR_FORMULATION.md`。

## 2. WaterLevel 与初始/边界状态审计

坐标 `y` 向上，域为 `0--0.20 m`。原代码的 Dirichlet 压力为

```text
p_b = p_n - rho(x_b) g (WaterLevel+y_b).
```

因此 `WaterLevel=0.01 m` 表示参考水位在 `y=-0.01 m`，不是位于底面以上
1 cm。底面 `y=0` 的记录压力为 `99891.6996 Pa`。实际接受初始场与水库
Dirichlet 均为 `x_NaCl=0.05`；对应初始表面质量分数为 `0.145833737`。
顶部只使用 P2-H 气膜/ALE 通量，没有叠加输入文件中的固定蒸发率。

## 3. 短窗验证

HPCC 计算节点上的三项验证全部通过：

- 无蒸发静水 reservoir：100 s 内库存、表面状态无变化；数值底部反应小于
  `1.8e-17 kg/s`；
- reservoir 蒸发：底部水/盐通量为非零并按接受步累积；
- no_flux 回归：新旧冻结二进制的 601 行共同量逐值一致，最大绝对差为 0。

短窗最大盐/水相对残差分别约为 `1.94e-14/1.96e-14`（静水）、
`4.20e-15/5.03e-15`（蒸发 reservoir）和
`1.42e-14/1.56e-14`（no_flux）。这些结果支持开放边界账本的数值实现，
不验证盐层物理。

## 4. 50 h pilot 结果

参考算例为 `k_r=1e-3 m/s`、`alpha_av=1`、土壤 80 层、ALE 64 层、
`dt_max=0.5 s`。它完整到达 `180000 s`，求解器退出码为 0。

| 量 | 结果 |
|---|---:|
| 最终表面 NaCl 质量分数 | 0.262856472 |
| 平衡质量分数 | 0.264940870 |
| 与平衡值的绝对差 | 0.002084398 |
| 最终表面 `Sw` | 0.999955108 |
| 最终底面 `Sw` | 1.0 |
| 累计蒸发水 | 3.689868 kg/m² |
| 累计底部净供水 | 3.471427 kg/m² |
| 累计底部入盐 | 0.592685 kg/m² |
| 最终蒸发率 | 1.797899e-5 kg m⁻² s⁻¹ |
| 表面固体 | 0 kg/m² |
| ALE 激活 | 否 |
| 盐/水最大相对残差 | 6.53e-13 / 2.27e-13 |

底部供水约补偿累计蒸发的 94.08%，其余来自土柱液相库存的轻微下降。底部
输入的盐全部保存在溶解相，没有被错误消失或转成未记录固体。表面
`Sw` 全程维持近 1，证明 reservoir 真实解决了旧算例的失饱和；但同一补水也
减弱蒸发浓缩，使 50 h 终点仍低于溶解度。因此本轮不是“有水但激活器失败”，
而是根本尚未发生表面析盐。

## 5. 与旧 no_flux 的受控比较

旧 no_flux 参考在 `108399 s` 首次析盐、`108996 s` 首次尝试激活；尝试时
表面 `Sw=0.864725`，因此被 `Sw_min=0.99` 守恒拒绝。到 50 h，旧算例表面
`Sw=0.803329`，质量分数被析盐闭合钉在平衡值附近。

新 reservoir 算例则把表面维持在 `Sw=0.999955`，但 50 h 内尚未达到平衡。
因此 reservoir 不是简单地“修复旧激活”：它消除了孔隙液供给筛查阻塞，却在
给定 `x_NaCl=0.05`、气膜和 50 h 窗口内产生了新的时间尺度限制。延长时间可能
最终达到平衡是合理假设，但本任务没有授权 50 h 以后计算，不能用外推替代证据。

## 6. 为什么没有执行参数矩阵

`k_r` 和 `alpha_av` 只进入 ALE 内部反应/比表面积闭合。参考 pilot 没有任何
接受的 ALE 状态，故参数在活动方程中从未被调用。此时运行五个不同参数算例
只会重复同一预激活土壤轨迹，不能形成参数敏感性证据。依赖作业
`16430445`、`16430446_[0-4]`、`16430448` 已取消且从未调用求解器。

所以以下结论均为 **NOT TESTED**：

- `k_r` 或 `a_v` 对内部/顶部结晶分配的影响；
- 孔隙率下降对蒸发的反馈及出现时间；
- ALE64 局部最小孔隙率或堵塞时间的网格收敛；
- 五算例 50 h 高度、孔隙率和内部沉淀排序。

将“矩阵未运行”解释为“参数不敏感”会构成明确的证据—结论不匹配。

## 9. 物理边界与下一步

`0.1 µm` 仅是固体等效激活阈值，小于估计晶粒尺度 `3.5 µm`；即使未来激活，
它也不能证明连续 ALE 盐层在该尺度有效。当前结果只说明 reservoir 边界在现有
方程中能保持供水和守恒，不能验证真实土壤—盐壳毛细充液机制。

推荐下一步单独注册为“时间窗扩展/触发时间研究”：保持本分支所有物理和数值
参数不变，先延长唯一参考算例直到真实析盐和至少一个可检验 ALE 窗口，再决定
是否启动矩阵。不得通过提高初始盐度、人工固体、固定供水通量或降低
`Sw_min` 来强行通过。若获得 ALE 状态，必须先完成 ALE128 与 `dt/2` 对局部
孔隙率/堵塞时间的检查，再讨论 `k_r/a_v`。
