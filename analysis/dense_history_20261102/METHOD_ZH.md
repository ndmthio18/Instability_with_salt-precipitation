# 历史密集时序分析方法与解释边界

本工作只解析冻结审计中全部 14 条具有 101 帧的运行。长时间文件解析在 frodo 上进行，原输入、VTU、PVD、profile、manifest 和每步诊断只读。新文件写入独立 `paper2_history_analysis_20261102_r02`，本地结果位于本目录。没有执行求解器。

## 身份与时间

1. 逐个输入、PVD、profile、原 manifest 及 sigmatop 的哈希须与 Phase 0 快照一致。每帧另记原始路径、大小、修改时间与 SHA-256。
2. 核对网格为固定二维张量积网格，节点/单元数量与输入一致。检查有限值和物理取值。
3. 按明确输入中的密度公式与保水曲线核对每帧 rho(x)、Sw(p)；同时记录旧默认密度公式的误差。字段一致不能替代历史 executable 哈希证据，也不能单凭 rho/Sw 输出证明实际 krw 残差路径。
4. 从完整场重算表面节点均值和标准差，与每步 sigmatop 对应。旧 PVD 使用约六位有效数字，初次严格时间检查会保留 `structural_review_required`。后处理仅在最近诊断时刻唯一、该时刻按六位有效数字舍入等于 PVD 时刻、场统计量也相符时，采用更高精度的诊断时刻。原始审核状态不改写，逐帧映射另存 `time_reconciliation.csv`。

## 库存计算

对固定直角 BOX 网格，用相邻顶点中点围成的节点控制体权重计算

`I_s = sum(phi Sw x DeltaV)/W`，`I_w = sum(phi Sw DeltaV)/W`。

单位均为 m，采用单位出平面厚度；没有乘以变密度或摩尔密度。三个目标切面为 z/H=0.9、0.75、0.5，取最近的相邻顶点层中点，保存实际值，不把它们标成精确几何截面。初末帧再用单元面积乘四角值平均的独立累加顺序检查积分。

`C_proxy(t)=I_s(0)-I_s(t)` 为库存反推的累计向下净交换代理。其正号表示上部库存低于初始值，负号表示累积增加。解释需要顶部/侧面零盐交换和可忽略预算残差；历史运行没有独立面通量记录，不能声称已验证这些运行的离散预算。

同时计算相对初始库存变化、相对于此前最大库存的回落，以及每个相邻保存帧之间的库存增减。1e-8 倍初始库存仅用于过滤浮点量级符号噪声的描述性筛选，不是物理有效输运阈值或数值误差上限。

全域库存变化与上部库存变化分开报告。底部固定浓度储库可提供盐输入，因此不能要求全域库存恒定。上部库存增加也不能排除其相对于无扰动背景的增加有所减缓。没有背景配对，不能识别不稳定性导致的额外输运 Delta C。

## 事件和有效窗口

逐帧计算表面面积均值、节点均值/标准差、表面最大值和全域最大/最小值。首次观测到 x>=0.1 的帧及此前保存帧构成“首次观测跨阈区间”。这不排除更早未保存时刻的局部越界和回落。每步表面均值达到 0.1 可给出局部越界时刻的上界，不能给出首次局部越界的精确时刻。

汇总的前阈窗口保守排除首次观测到全域越界的那一帧及之后的所有帧。它表示“首次观测越界前”，不等于连续时间全程未越界已被证明。越界数据保留，在图中淡化或灰色标记。

原 onset 类别、拟合时间及区间原样保留，图上用区间表示，不把浅极小值变成精确时刻。不定义 t_eff，不按效果选取有利阈值。

## 同案例比较

14 条记录只覆盖 10 个物理案例。同一 case 不同模态、网格、时间步和窗口不能拼接为一条轨迹或视为单因素因果对照。只有物理参数、网格、模态、profile 字节一致，差异仅在输出/时间设置的运行，才在共同保存时刻比较库存敏感性。此比较仅覆盖已有重叠窗口，不能当作整个非线性阶段的收敛验证。

VTK velocity 不进入通量计算。平流/扩散分解、连续时间的局部越界、实际预算残差、无扰动背景和显著性误差包络都仍缺失。
