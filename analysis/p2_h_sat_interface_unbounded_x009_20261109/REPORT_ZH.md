# 盐层侧饱和、禁止溶解、无欠饱和停止阈值：12500 s 诊断

## 结论

80 层土壤、初始 NaCl 摩尔分数 0.09、3.5 μm 激活、64 个 ALE 单元的对照算例在取消土壤侧欠饱和跳跃停止阈值后，实际完成到 12500 s。计算没有触发 `Sw >= 0.99`、ALE 状态边界或非线性求解器停止，水盐质量守恒也保持良好。

但是，这不构成当前界面闭合的物理验证。盐层侧底面被固定为饱和质量分数 0.26494087，而土壤表面最终降至 0.25136263，形成 0.01357824 的绝对跳跃，即相对饱和值约 5.13%。模型能够走完，是因为允许这个没有界面传质本构支撑的跳跃持续增大，而不是因为两侧达到局部平衡。

## 配置

- 分支：`research/p2-h-saturated-interface-no-dissolution-x009`
- 土壤网格：80 层；一列 BOX 网格
- 初始 NaCl 摩尔分数：0.09
- ALE 激活高度：3.5 μm；零人工种子
- ALE 单元：64；`epsilon_birth = 0.43`
- 内部溶解：禁止
- 界面相变源：0
- 盐层侧底面：`C = C_eq`
- 土壤侧：不施加欠饱和跳跃停止阈值
- 时间步：0.5 s；终点：12500 s

仅新增 `P2H.EnforceSoilSideUndersaturationBound=false`。默认值仍为 `true`，旧的有界案例不改变。饱和度筛查、ALE 物理状态边界、求解器检查和全局质量守恒检查均保留。

## 科学判断

1. **数值完成：PASS。** 作业和求解器退出码均为 0，达到请求终点。
2. **水盐守恒：PASS。** 残差远低于 `1e-8` 门槛，且没有溶解或界面盐源补账。
3. **土壤侧饱和界面：FAIL。** 最终土壤侧比饱和值低 1.358 个质量百分数点。
4. **局部平衡解释：FAIL。** 盐层侧 Dirichlet 饱和与土壤侧自由浓度之间缺少界面传质/相变互补关系；完成计算不能证明该浓度跳跃合理。
5. **盐层状态界限：PASS（仅数值）。** 最低孔隙率没有接近 0.02，但这不验证内部析盐动力学。

因此，取消停止阈值回答了“最后会怎样”：现有方程可以守恒地走到 12500 s，并给出更高盐层；代价是界面两侧浓度越来越不连续。这个结果支持把原 `1e-4` 看作适用性诊断，而不是导致失败的数值障碍。若研究目标是界面局部平衡，下一步仍需让界面相变率或传质通量由守恒与互补条件共同求解，不能简单删除适用性边界后把该解当作物理解。
