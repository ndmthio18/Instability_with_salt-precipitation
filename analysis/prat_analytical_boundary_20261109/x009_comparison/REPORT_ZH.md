# x=0.09：解析边界与既有ALE条件对照

## 结论

按追加请求完成两组真实DuMux计算：初始和底部储液槽NaCl摩尔分数均为**0.09**，解析边界kr分别为**2.3×10⁻³和1×10⁻³ m/s**。两组都成功激活，且水盐守恒通过；但都在25000 s之前因土壤界面低于近饱和平衡有效域而停止，**耦合终点门槛FAIL、定量研究NO-GO**。降低kr延后失效，未解决供盐闭合问题。

对照使用已有真实0.09结果：可逆反应ALE、禁止内部溶解ALE，以及可逆ALE旧dt/2检查。没有重跑或改写这些历史算例。原0.08实现及先导结果见上级 `REPORT_ZH.md`。

## 输入和证据可比性

全部对照的土壤域0.001×0.20 m、单横向单元、80层、Grading1=-0.97、初始/底部x=0.09、储液槽边界、地下水位参数0.01 m、土壤本构、扩散率和溶解度相同，常规最大步长0.5 s；唯一旧时间步对照为0.25 s。`effective_inputs.csv`由输入文件及命令行覆盖合成，并逐项核验相同土壤设置。

各组采用实际表面析盐形成初始固体、渐进孔液填充、3.5 μm激活，不添加种子。所有常规0.5 s组首次析盐**4314.5 s**、接受激活**6745 s**。独立预激活回归中，解析两组与旧可逆ALE的土壤表面C、Sw及蒸发逐值相同，固体等效高度最大差仅8.47×10⁻²² m，见 `preactivation_regression.csv`。差异开始于激活后的闭合。

| 条件 | kr (m/s) | 盐层网格 | 孔隙率 | 内部反应 |
|---|---:|---:|---|---|
| 解析默认 | 0.0023 | 无 | 固定0.43 | 不建模 |
| 解析匹配kr | 0.001 | 无 | 固定0.43 | 不建模 |
| 旧可逆ALE | 0.001 | 64格 | 演化 | 可析盐、可溶解 |
| 旧禁止溶解ALE | 0.001 | 64格 | 演化 | R=max(R,0)，仍有内部析盐 |

因此“禁止内部溶解”**不等于**“无内部反应”。匹配kr消除了一项参数混杂，但还存在供盐/输运闭合、内部反应及孔隙率处理的联合差异，不能将全部效应归因于取消网格这一单一因素。

## 验证及物理判定

- 两组新解析算例最大组合水盐相对残差分别不超过**3.42×10⁻¹⁴、3.46×10⁻¹⁴**：PASS。
- 逐步表面库存—边界通量相对差最大约**1.05×10⁻¹⁹**，激活转移相对差约**1.15×10⁻²⁰**：PASS。
- 独立有限Da公式重算速度相对误差不超过**7.14×10⁻¹⁶**：PASS。
- 新解析两组最后接受Sw约0.999909、Pe_U<4.62×10⁻⁴、Pe_move<4.45×10⁻⁵，均满足筛选。触发停止的是**土壤界面浓度有效域**。
- 25000 s完整解析耦合：两组FAIL。解析版网格/完整时间步收敛：NOT TESTED；既有ALE的dt/2结果不能替代新解析版的收敛证明。
- 旧禁止溶解算例虽然完成终点且守恒通过，仍是人为抑制负反应的机制反事实，不能自动获得物理有效性或定量预测资格。

与0.08默认解析先导比较，浓度提高使首次析盐从19048.5 s提前至4314.5 s、激活从23136 s提前至6745 s，但没有移除激活后供盐闭合的有效域失效。现有证据不支持靠提高初始浓度或调整kr就获得可靠长期盐层增长预测。

下一步仍应先建立实际土壤界面浓度、盐通量和生长速度的联立闭合，明确欠饱和下的界面固体处理，再重做先导。禁止溶解、固定界面浓度或增长裁剪都不是本轮擅自采用的修复。
