## 3. 浓度停止与事件约定

每个接受步检查surface max与domain max；任一达到0.1，写入触发位置、max、前一接受时刻t_low、当前t_high、最后低于阈值场和第一触发场，**不再推进下一步**。Newton中间迭代不当作物理事件。跨阈值步可能轻微超调，触发场只用于事件定位，不用于阈值后的物理主张。单纯将时间积分跑到远大于0.1再后处理截断不合格。

现有实现只能给区间，不能声称精确在x=0.1连续时刻停下。两腿均记录阈值区间；接近阈值x_max≥0.09时保存每步场并检查增长/超调。如时间区间太宽或延迟符号不稳，使用成对dt/2从零复核，仍不运行越阈值后的动力学。阈值事件的时间步复核不以“出现显著输运”为前提。

定义tau_any为surface/domain首次触发的最早事件；tau_surface单独记录。domain先在内部触发时，后续surface时间未观测且受模型适用域截断，不填入全域事件时间。若两腿都观测到同类事件，Delta tau=tau_M1−tau_M0（正为延迟），区间为[l1−u0,u1−l0]；若只有一腿触发，给相应单侧界限，若两者未触发则不报点估计。事件类型不同不得混成“表面延迟”。不外推溶解度之后的结晶动力学。
