# P2-H reservoir：初始与底部储液层均设为 `x_NaCl = 0.08`

## 结论

本轮成功解决了上一版 `x_NaCl = 0.05` 在 50 h 内没有表面析盐的问题：

- 实际接受的初始场和底部 reservoir Dirichlet 条件均为摩尔分数 `0.08`；
- 首次表面析盐发生于 `19048.5 s`（`5.2913 h`）；
- 真实表面固体达到 `0.1 um` 等效高度后，ALE 于 `19383.5 s`（`5.3843 h`）守恒激活；
- 不使用人工盐种，没有降低 `Sw_min = 0.99`，也没有修改 Prat、M3 ALE、反应或气膜参数。

但是 50 h 先导算例没有通过。最后接受时刻为 `20580.510687 s`（`5.7168 h`），仅在 ALE 激活后演化 `1197.010687 s`。第一拒绝试算态在 `20581.0 s` 出现，ALE 最靠近土壤的第 0 单元孔隙率从最后接受值 `0.9499999999` 增至 `0.9500896721`，超过模型规定的严格上界 `epsilon < 0.95`。因此科学状态为：

> **FAIL_ALE_UPPER_POROSITY_BOUND / NO-GO**

由于预注册的 50 h pilot 门槛失败，ALE128、时间步减半及五组 `k_r/a_v` 参数矩阵均未运行。不能用本轮结果评价 `k_r` 或 `a_v` 敏感性。

## 根因诊断

原始标量输出不足以区分低孔隙率堵塞与高孔隙率失效，因此在另一计算节点用同一物理配置重复运行，并保存全部 64 个 ALE 单元的最后接受态及第一拒绝试算态。

诊断结果是：

1. 最后接受态 `epsilon_min = 0.38754`，远高于停止下界 `0.02`；不存在快速低孔隙率堵塞。
2. 唯一越界的是第 0 个 ALE 单元，位于土壤表面上方约 `0.020 um`。
3. 该单元第一拒绝试算态 `epsilon = 0.9500896721`；其他单元及全部浓度均在界内。
4. 最后接受态浓度范围 `0.2649359014–0.2649424525`，底部局部略低于平衡浓度。
5. 内部溶解 `0.6225 g m^-2` 明显大于正内部沉淀 `0.0674 g m^-2`，净内部固体为负；这与底部单元增孔相一致。
6. 23 个拒绝试算均不能回到合法域；同一故障在不同节点被重现，因此不是单次硬件或调度异常。

所以，`x=0.08` 的确使模型进入析盐/ALE 阶段，但暴露出另一项更基本的闭合问题：新生盐壳在轻微欠饱和液体作用下发生净内部溶解，现有 ALE 固相/相消失处理允许底部单元趋近非物理的近全孔隙状态，却没有守恒的盐壳消失、回退或重新成核规则。

这属于**构成闭合与相状态转换问题**，不是通过放宽 `epsilon < 0.95`、裁剪孔隙率或删除溶解项即可严谨修复的普通收敛问题。当前证据不支持降低上界或继续参数矩阵。

## 顶级论文标准下的判断

| 主张 | 证据状态 | 判断 |
|---|---|---|
| `x=0.08` 能在本配置下产生表面析盐 | 有实际 DuMux 接受步与固体库存 | PASS |
| `x=0.08` 能守恒触发 ALE | 激活转移残差为 0 | PASS |
| `x=0.08` 可支持 50 h 盐壳演化 | 仅到 5.72 h 即越界 | FAIL |
| 失败由质量不守恒导致 | 水盐残差均约 `2.5e-14` | 否 |
| 失败由低孔隙率堵塞导致 | `epsilon_min = 0.388` | 否 |
| 当前结果可用于 `k_r/a_v` 定量比较 | 参数尚未进入完整、通过门槛的长期轨迹 | FAIL / NOT TESTED |

因此，本版本适合证明“提高初始与 reservoir 盐度能够触发析盐和守恒激活”，但不适合用于定量 1D 盐壳生长或参数敏感性论文结论。

## 推荐的下一步

下一步应先定义并单独验证一个守恒的盐壳相消失/再激活闭合，例如固相不可为负的互补条件、固体完全溶解时 ALE 去激活并把剩余液体/盐返还土壤，以及再次达到成核阈值后的重激活。该规则需要明确的物理假设和独立单元测试；在此之前不应：

- 放宽 `epsilon < 0.95`；
- 对孔隙率或浓度做无账本裁剪；
- 跳过 pilot 直接运行 `k_r/a_v` 矩阵；
- 把短暂成功激活等同于长期模型有效。
