# 配对时间步敏感性：方法与证据边界

指令：`command/9.md`；基线提交 `7db1dd3f5b9ee98802d46c2d5fecfaf913c5d68d`。只新增 M1 dt/2 一条计算，M0 dt/2 复用 command/8 已验收结果。旧计划、结果、源码和 ELF 保持不变。

## 两个严格协议

原协议：M0(dt) 与 M1(dt)，dt=227.3717729539139 s。

细化协议：M0(dt/2) 与 M1(dt/2)，dt/2=113.68588647695695 s。每个协议内部独立核验退出码、接受时间、合法停止、初始场、七面收支和哈希；通过已验证异步停止接口选择较早 crossing 前的共同实际接受状态。绝不把细步 M0 与粗步 M1 相减。

两协议都用 Case 36877、canonical nx28、24×200、W=0.6/28 m、原 A28、M1 幅值 1e-6、相同七面及 0.1 阈值。原 M1 参数中 `StandardDeviationSaltMoleFraction=1e-6` 及 `EigenprofilePath` 原样保留；初始化类型仍为 Eigenprofile，没有引入随机初始场。新增 M1 相对旧 M1 只改名称和两个时间步参数。

守恒量为 φSwx；单位宽度库存与累计通量单位 m，通量 m/s，并非 kg/mol。定义 ΔC=C_M1−C_M0，D_I=(I_M1−I_M0)−(I_M1(0)−I_M0(0))，采用正向下约定。保留逐面恒等式 D_I+ΔC=R_M1−R_M0；初始库存差不强置零。

## 物理时刻与 U_dt

U_dt=abs(ΔC_fine−ΔC_coarse)。只有实际接受时刻严格相等时，直接称为同一时刻的敏感性。两个协议各自的名义 2T 终点不同，表格明确列出两个时间，不对累计通量插值。

对于不相等但处于较晚协议最后一个已有接受步内的比较，取较早时刻 t*；原始端点差为 U_raw。用较晚协议两腿记录的保守通量给出数值积分尾段上界：

`B = Σ(M0,M1){ |t_late−t*| (|q_adv|+|q_diff|) + |[C_n−C_(n−1)]−q_total[t_n−t_(n−1)]| + 8 max(ulp(C_n),ulp(C_(n−1))) }`。

报告同一 t* 下敏感性的包络 `[max(0,U_raw−B), U_raw+B]`。第二项保留实际时间递推与累计积分的浮点差，第三项是局部浮点保护量。加总 adv/diff 的绝对值不依赖抵消。只产生界，不生成所谓“插值后的累计通量”。

该界基于既有独立再积分验证的后向 Euler 接受步常通量积分约定；**仅约束已记录离散守恒积分的时钟差异**，不声称约束未知连续解的步内波动，也不包含空间/缩域误差。不允许外推到已停止腿之后。时间差为零时直接比较，所有实际时刻保存在 CSV。

加权 σ、傅里叶幅值、放大倍数、表面均值/最大值和垂向剖面同时报告原始终点时刻，并在最近的严格共同时刻另比剖面。原数值检测函数保持冻结；检测区间/平台宽度不是统计置信区间，也不是 t_eff。

## 分开的 A/B 决策

独立登记 `amendment_20261103_C01.json` 在新增 M1 启动之前写入并锁定 SHA。它是在已知 M0 背景复核之后制定的**工程探索判据**，并非对历史数据盲设的统计检验，也没有修改原 M0 1e-12 门槛：原失败永久保留。

A 仅用于评审有界 4T 增长/空间结构探索：增长与幅值的步长变化 ≤5%，垂向 σ 剖面加权相对 L2 差 ≤5%，表面均值/最大值差 ≤0.1%，数值检测差 ≤max(两个粗步,2%原检测时刻)，背景 σ 至少比 M1 小 1000 倍，并通过原 M1 对称性和核心收支。5% 是识别明显协议依赖的探索容差，0.1% 对均态更严格，1000 倍隔离沿用原相对对称性余量的尺度；它们都不是微小输运的精度保证。

B 才涉及定量输运和溶解度延迟：必须有配对时间误差与空间、完整域误差控制，并有能识别阈值时间差的事件证据。单次步长减半只给敏感性，不建立收敛阶；U_z、U_x、U_domain 继续 unknown。A 的通过不能代替 B。

本轮没有 4T/8T 启动许可，不更改 Paper 1，不定义 t_eff。即使 A 支持，也只提出下一次单独授权的探索计划。

## 成本和复现

新运行使用 frodo 一个物理核；启动前核验内存、磁盘、CPU及原 ELF。管理器以独立进程组执行整条 worker，3600 s 到限杀死进程组；原求解包装器另设 3500 s 上限。硬限时覆盖求解、后处理、压缩，失败保留原场、不重试。超时分支在启动前用短暂非求解器任务测试。

使用已有 `wp6_post.py` 进行逐帧初始场/库存与守恒通量再积分；其“独立”是库存与积分独立，不是第二套通量内核。原场保留远端，同时下载到忽略目录并逐成员核验 SHA。

只读本地后处理：

```text
python scripts/analyze_wp6_timestep.py
python scripts/plot_wp6_timestep.py
python scripts/verify_wp6_timestep.py
```

严格细步配对由冻结的新接口 `analyze_wp6_review.py --m0 <旧M0细步目录> --m1 <本轮M1细步目录> --out <新的refined_pair目录>` 生成，目标目录必须新建。不要重复运行准备或 launch。归档缺失时只使用 `wp6_timestep_campaign.py collect dt_half` / `archive dt_half` 回收已有运行。
