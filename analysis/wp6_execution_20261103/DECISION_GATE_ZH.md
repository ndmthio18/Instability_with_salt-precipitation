# 2T后的研究决策：已完成首阶段观测，暂停于4T准入门槛

本轮按command/7完成T桥接和2T配对，所有计算已结束并归档。没有启动4T、8T、672×200全域、多波长或nx60实验。

## 科学发现与证据界限

1. **增长确实继续。** 加权sigma从最低点至2T为3.07583倍，而T时约1.19倍；末端绝对sigma约2.04e-6 mol/mol。但sigma/mean只有6.37e-5，表面2/3次谐波能量比例1.86e-7，尚无显著多模态/强非线性结构证据。空间异常主要位于上部数毫米，保持单周期形状。
2. **浅面提供了新观察，尚未确立有效输运。** 1.029 mm处Delta C为2.7279e-15 m，约初始该区库存7.03e-9；已高于该面闭合包络（窗口最大1.62e-16 m），不能一概称为“仍与闭合残差同阶”。但仍低于冻结候选线1e-13 m，仅为其2.7%，时间/网格/域误差未知。深部三个面仍主要是约1e-17 m差值。全部7面保持unresolved，没有t_eff。
3. **总通量方向不能从Delta C推断。** 2T末M1最浅面adv=-4.11456e-11、diff=+3.46230e-11、total=-6.52256e-12 m/s。正的额外累计差并不等于实际净向下盐迁移；此面仍为净向上，扩散向下部分抵消向上平流。M0对应有符号量和其他深度均在`signed_flux_end.csv`。
4. **尚无真实溶解度事件。** M1局部最大0.0320656，M0约0.0320627，均未达到0.1。阈值时间右删失，配对阈值时间差尚不可识别，不能用两者浓度微差外推“盐析延迟”。

## 不能省略的质量筛查结果

T桥接全部通过：两腿共1202帧与WP5原始VTU逐字节相同；新增诊断没有改变旧解。2T核心数值质量、实际切面、初始库存、接受时间、密度/饱和度、独立库存及盐水闭合检查通过。

但是，冻结WP6 G1给出的端点对称性绝对下限为1e-12 mol/mol。M0在2T的最大端点差为2.4316e-12，超线约2.43倍；M0最大sigma为1.2516e-12。M1端点差量级相似，但相对当前主扰动幅值远低于其1e-3筛查线。原规则对无扰动背景的适用性值得复核，但本轮采用保守解释：保留 `M0/absolute_endpoint_screen=false`，总体GO门槛不标通过，`domain_gate=review_required`。

这项超线是数值背景对称性筛查触发，不是已证明长波失稳、指状流合并或物理模型错误。不能通过把背景噪声归零、删除该字段或事后提高容差使结果“通过”。也不能将仅M1相对对称性通过推广为完整域代表性验证。

## 4T是否值得做

**科学上有理由继续一次有界观测，当前执行门槛仍为HOLD/NO-GO。** 理由是增长尚在延续、浅层差值随时间累积、浓度未触边界，进一步窗口能检验是否接近可分辨输运；不是因为预期必须得到阳性结果。按本次2T每腿188.6 s外推，4T每腿约6.3 min，5倍规划余量约31.4 min；这是工作量情景，不保证非线性阶段成本。

准入前需要解决背景端点筛查：先用保留场检查镜像/奇模态与压力/浓度数值噪声，提出独立的2T背景重现/时间步或小型多波长检查；如需区分背景绝对噪声门槛与有种子扰动相对门槛，应根据独立误差证据另作带日期修订，并在任何4T结果前冻结。不能仅据当前超线数值反向挑选新阈值。新计算均需后续授权，本轮未启动。
