# 盐层侧饱和、土壤侧轻微欠饱和、禁止溶解：兼容性试验

日期：2026-11-09。分支：`research/p2-h-saturated-interface-no-dissolution-x009`，基线：`fdd4d1f306c09caf3f44cac39f9cc7431aadfaa0`。

## 结论

在现有 xNaCl=0.09、80层土壤、64个ALE单元、`dt=0.5 s`、有限速率顶部生长和气膜蒸发条件下，盐层侧固定为饱和、禁止内部溶解、界面相变源为零时，土壤侧欠饱和跳跃不是稳定的小量。

- 严格要求两侧饱和：6745 s激活成功，6745.5 s首个激活后步得到 `C_soil-C_eq=-9.7920e-6`，事务性拒绝。
- 允许土壤侧最多欠饱和`1e-4`：接受6745.5–6750 s共10步；6750.5 s试算达到`-1.06278e-4`并停止。
- 该差值约以`1.93e-5 s^-1`增长。把容差继续调大只会接受更大的、未经标定的浓度跳跃，不能证明界面闭合成立。
- 所有接受状态的盐/水最大相对残差分别为`2.4880e-14`和`3.3440e-14`。界面相变源和内部溶解均严格为零；拒绝试算没有写入库存。

因此，本试验对“保持一个小的土壤侧欠饱和跳跃直到12500 s”给出 **FAIL**。它不证明任何允许有限界面传质阻力的模型都无解；它说明当前方程没有使该跳跃稳定的本构关系。

## 条件与定义

盐层ALE底部边界面规定：

`C_crust,face = C_eq = 0.2649408697676898`。

土壤侧不投影浓度；DuMux接收ALE算出的守恒液体和盐通量。接受条件为：

`-1e-4 <= C_soil-C_eq <= 5e-13`，并保留`Sw>=0.99`。

同时固定：

- `P2H.SuppressDissolution=true`；
- 界面相变源为0；
- 不增加盐库、不进行骨架下沉；
- 不修改内部反应系数、Prat顶部动力学、气膜、土壤方程、激活和求解容差。

这是一个允许同一液相浓度跨界面跳跃的数值对照。没有显式界面传质阻力或分配系数，因此不能把`1e-4`解释为材料参数。

试算原请求到12500 s，但真实最后接受时刻为6750 s，不外推。

## 验证与限制

- HPCC构建作业16460995通过原严格模式；修订后构建作业16461380完成，ALE局部盐积分测试最坏相对误差`3.31591e-15`。
- 修订后耦合作业16461382在计算节点`ibc11b11n11`完成诊断包装；内部求解器按预声明界面跳跃上限返回非零，包装器核验拒绝原因和回滚后以0退出。
- 最初构建16460637因源路径错误在编译前失败；16460638因源包缺少冻结P1-R2模板在DuMux准备前失败。两者日志保留，没有数值结果。
- 未进行网格、时间步或跳跃上限敏感性。当前结果只能判定这套未标定浓度跳跃闭合在所选阈值下不可持续。

下一步若仍希望盐层侧保持饱和，应显式选择并验证至少一种机制：有限界面传质阻力、有限固体溶解/耗尽，或供盐受限的蒸发通量。单纯放宽浓度跳跃上限不构成物理模型。
