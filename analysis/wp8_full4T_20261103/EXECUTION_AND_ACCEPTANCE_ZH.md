## 3 强制验收（48 项，全部通过）

验收脚本 `scripts/validate_wp8_full4t.py` 独立于求解器重建全部守恒量，`validation.json`
记录结果。

**每一步的横向均匀性、固定步长与阈值状态**

- 4801 帧全部 `max|Δ_x x| = 0`、`max|Δ_x p_w| = 0`（精确相等，不是落在 1e-14 门槛内）。
- 每个接受时刻**逐位等于** dt 的双精度累加（drift = 0.0）。因此末点与十进制 `TEnd`
  相差 2.794e-8 s 是 4800 次加法的累加舍入，远小于累加预算 4800·ulp(TEnd) = 5.588e-7 s；
  要求末点按 32 ULP 等于 `TEnd` 在数值上是不可能满足的，不作为门禁。
- 全程 `max x = 0.056968936640` < 0.1，**未触及局部溶解度阈值**，因而本次不是删失结果；
  阈值标志与 `x_domain_max ≥ x_top_max` 在 4801 个状态上逐一自洽。

**Newton 收敛**

- 4800 个接受步各有且仅有一次 `WP8_CONSTRAINT` 成功记录；日志中没有任何失败尝试

- 迭代次数：最少 3、最多 5、平均 3.024，分布 {3: 4686, 4: 113, 5: 1}。
